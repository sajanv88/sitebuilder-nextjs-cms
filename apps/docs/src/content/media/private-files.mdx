Like every file on a website, a file you upload is public: anyone who has its address can open it. That's what you want for the pictures on your pages. For something only some people should see, such as a price list for trade customers, make the file private and send them a share link.

## Make a file private

1. In **Media**, click the file.
2. Under **Who can see it**, turn on **Private**.

It applies at once. From then on, only people who can sign in to your admin can open the file, plus anyone with a share link while the link lasts. Its address stays the same; visitors who try it without a link are turned away.

A file that a page or post uses stays public, because your visitors need to see it. The switch is greyed out until you take the file out of everything under **Used in**. In the same way, a private file isn't offered when you choose a picture for a block.

Turn **Private** off to make the file public again.

## Share a private file

1. Choose how long the link should work: **An hour**, **A day**, **A week** or **30 days**.
2. Press **Make a share link**.
3. Press **Copy**, and send the link to whoever needs it.

<Screenshot src={mediaPrivate} alt="Who can see it for wholesale-prices.pdf: Private turned on, A day chosen, and a share link below with a Copy button, working until the next day." />

Anyone with the link can open the file until the time shown, even without an account. A link can't be cancelled early, so choose the shortest time that works, and make a new link if they need more.

Making the file public and private again doesn't stop links you've already sent. To be sure a file can't be opened, delete it.
